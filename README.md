# Indian Air Force - Tribute & Information Portal

A responsive, multi-page web application dedicated to showcasing the history, assets, and grandeur of the Indian Air Force (IAF). Built as an informational portal, this project integrates interactive elements, multimedia, and structured navigation to give users an engaging overview of the "Guardians of the Sky."

## 🚀 Features

*   **Interactive Navigation:** A clean header menu providing smooth access to the Introduction, Fighter Jets, and Helicopters segments.
*   **Historical Overview:** Informational sections highlighting the establishment, role, and the official motto: *"Touch the sky with glory."*
*   **Multimedia Integration:** Includes dedicated sections for an Indian Air Force documentary video player.
*   **Interactive Air Force Bases Map:** Features an external interactive mapping page (`map.html`) that allows users to explore key IAF bases across the country visually.
*   **Responsive Styling:** Vibrant, theme-appropriate gradient backgrounds reflecting the sky, paired with clean typography and rounded visual cards.

## 🛠️ Tech Stack

*   **HTML5:** Structured layouts for multi-page routing (`wd.html`, `map.html`).
*   **CSS3:** Custom gradient styling, flex layouts, typography configurations, and responsive image properties.
